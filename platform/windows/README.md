# Windows Platform Layer (Future Target)

This directory will hold Windows-specific configurations, installer assets, and OS-level integrations when Windows support is enabled in a future phase.

## Scope
- Windows installer configuration (NSIS / WiX for `.exe` distribution)
- Windows application manifest and registry integrations
- Windows-specific notification handling and protocol registrations

> Note: No fake Windows implementations are written at this stage. Shared business logic remains completely shared.
